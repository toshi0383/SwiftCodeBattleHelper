# Setup

## `bootstrap.sh`

Run `bootstrap.sh`  
Open `SwiftCodeBattleHelper.xcworkspace` and make sure `main.swift` is created under `CLIApp/Sources`.  
This is the file you are going to edit on Xcode.

## Change Location

Run the `SwiftCodeBattleHelper` macOS App target.  
Click "Change Location" button to set Location to `CLIApp/` folder created in the previous step.

## Keyboard shortcut

| Binding | Behavior |
|---|---|
| Cmd + Enter | Build main.swift and Run |
| Cmd + C | Copy main.swift content |
